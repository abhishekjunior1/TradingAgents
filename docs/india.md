# Indian markets (NSE / BSE)

TradingAgents analyzes NSE and BSE listings with Indian market data, rules and
reasoning. This page covers setup, the CLI, what each data source provides and
costs, what is not available, and the limits of the output. Facts below were
checked on 2026-10-29 against the sources named; rates and rules change, so
re-check them before relying on them.

> Research only. Reports are generated by AI agents from delayed or end-of-day
> data. They are not investment advice, not a prediction, and not research or
> advice from a SEBI-registered research analyst or investment adviser. The tool
> runs in research and paper-trading mode and places no orders; it has no broker
> integration and reads no brokerage credentials.

## Setup

```bash
cd TradingAgents                 # your clone of the repository
python3 -m venv .venv
.venv/bin/pip install --prefer-binary .
source .venv/bin/activate        # puts `tradingagents` on PATH in this shell
```

Choose an LLM provider: an API key (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, ...)
or, for a Claude Pro or Max plan, the `claude_code` provider (README, "Required
APIs"). Nothing else needs a key; `FRED_API_KEY` (free) adds India macro series.

Put Indian defaults in `.env` in the repository folder:

```bash
TRADINGAGENTS_DEFAULT_EXCHANGE=NSE      # bare tickers (RELIANCE) are NSE listings
TRADINGAGENTS_COST_PROFILE=india_equity_delivery
```

## Running

```bash
cd TradingAgents                                        # .env is read from the folder you run in
tradingagents --ticker RELIANCE.NS                      # asks the remaining questions
tradingagents --exchange nse --ticker RELIANCE --analysts market,news,fundamentals --save --no-show
tradingagents --ticker TCS.NS --benchmark "NIFTY IT"    # measure against a sector index
tradingagents --ticker INFY.NS --portfolio book.json    # size against your holdings (INR)
tradingagents --ticker HDFCBANK.NS --vendor news_data=yfinance,alpha_vantage
tradingagents --horizon intraday --exchange nse --ticker RELIANCE --analysts market,news   # a paper plan for one session

tradingagents market                                    # NSE session (IST), indices, India VIX, USD/INR, Brent
tradingagents market --watchlist HDFCBANK,ICICIBANK,SBIN   # plus these stocks, no model called
tradingagents backtest TCS,INFY --exchange nse --start 2026-06-01 --end 2026-09-30
```

`--watchlist` also takes the name of a list in your watchlists file
(`--watchlist banks`; see [Watchlists](#watchlists)). A name the file does not
have is read as a ticker, so define the list before using its name.

`python -m cli.main` works in place of `tradingagents` from the source folder.
From Python, `TradingAgentsGraph(...).propagate("RELIANCE.NS", "2026-10-28")`
(see `main.py`).

`--horizon intraday` plans one session instead of rating the position: an
intraday (MIS) paper plan that exits by your broker's square-off time, counts
intraday charges and is scored on that session's 5-minute bars. In Claude Code,
`/day-trader RELIANCE` runs it for one stock. See [docs/intraday.md](intraday.md)
for the session rules, broker square-off times, charges, leverage and Yahoo's
intraday limits.

US tickers after midnight IST: until New York's own midnight (09:30 IST, 10:30
IST while New York is on standard time) New York is still on the previous day,
and its regular session trades until 01:30 IST (02:30 IST in US winter). The
CLI's default date for a US ticker is then New York's, and a run dated it is
treated as a run dated today, not a past one: it gets the live company profile
and upcoming events, undated news (Yahoo's undated stories only until 05:30 IST,
when UTC's date moves on) and live web pages, and its lessons are not filtered as
a backtest's are.

### Watchlists

Keep them in `~/.tradingagents/watchlists.json` (or `TRADINGAGENTS_WATCHLISTS_FILE`):

```json
{"banks": ["HDFCBANK", "ICICIBANK", "SBIN", "KOTAKBANK"], "it": ["TCS", "INFY", "HCLTECH", "WIPRO"]}
```

No index constituent lists ship with the tool: they change at every rebalance.
NSE publishes them (for example `ind_nifty50list.csv`); niftyindices.com permits
personal, non-commercial use, and NSE's website terms prohibit automated
collection, so download a list by hand if you want one.

### Portfolio file (INR)

```json
{
  "cash": 500000, "currency": "INR",
  "positions": [
    {"ticker": "RELIANCE.NS", "quantity": 100, "average_price": 1200, "acquired": "2025-01-15", "sector": "Energy"},
    {"ticker": "TCS", "quantity": 50}
  ]
}
```

With a portfolio, the trader, risk and portfolio agents also get computed
figures: value in INR, per-holding 1-year volatility, drawdown and beta to NIFTY
50, sector exposure, concentration, unrealized P/L, an estimated capital-gains
tax when `acquired` is given, a sizing reference (risk `risk_per_trade_pct`,
default 1%, with a 2 x ATR(14) stop, capped at `max_position_pct`, default 20%),
and estimated charges. A book holding several currencies gets no totals.

## Indian market rules the agents use

- **Sessions (IST).** Pre-open 09:00-09:15; regular 09:15-15:30. From 3 Aug 2026,
  stocks with derivatives trade continuously to 15:15, then in a closing auction
  15:15-15:35; from 7 Dec 2026 the auction runs 15:30-15:40. Post-close ends 16:00,
  and only then is a day's close final. Sources: SEBI circulars of 16 Jan and
  15 Oct 2026; NSE/CMTR/75479, 76187. Agents are told only the rules in force on
  the analysis date.
- **Holidays.** The 2026 NSE list (NSE/CMTR/71775, 72260; BSE's matches) and the
  special Sunday sessions of 1 Feb (Union Budget) and 8 Nov (Muhurat) are in
  `tradingagents/markets/india_calendar.py`. Add each new year's list when the
  exchanges publish it (December); a year not listed is reported as not covered
  and only weekends count as closed.
- **Also given:** T+1 settlement; price bands and dynamic bands; market-wide
  circuit breakers (10/15/20%); SEBI LODR results deadlines (45 / 60 days); the
  RBI MPC schedule for 2026-27 (RBI press release of 23 Mar 2026); the Union Budget
  date; and the India-specific drivers to weigh (RBI, Budget, SEBI, FII/DII flows,
  the rupee, crude). Every agent is told to cite each claim's tool and date, mark
  assumptions, and report missing data instead of estimating it.

### News, insider trades and quarterly cash flow

- **Global news** for an NSE/BSE listing comes in two sections. *India*: Yahoo
  searches for `rupee`, `RBI` and `India` (`global_news_queries_india`), run as
  exact searches (`global_news_india_fuzzy: False`), keeping only stories whose
  title or summary names a term in `global_news_india_terms` (whole words, any
  case: India, Indian, SEBI, Sensex and the like), or two of
  `global_news_india_weak_terms` (rupee, RBI, Nifty, NSE, BSE), or that Yahoo
  tags with an `.NS`/`.BO` listing, an Indian index or the rupee. A weak term
  alone also names things outside India (the Pakistani rupee, Raiffeisen Bank
  International, Retail Banker International), so it needs a second India
  signal; untagged headlines that say only "RBI", such as one about an RBI rate
  rise in Yahoo's results on 2026-10-29, are dropped as a result. *Global*: the usual `global_news_queries`, unchanged. The
  article limit is split between them (India takes the odd one; a share one
  section leaves unused goes to the other). A section that shows nothing says
  whether the limit left it no room, the searches above already found its
  stories, or its search kept none. Yahoo carries little India news: on 2026-10-29 its fuzzy search
  answered "RBI monetary policy repo rate" with US stories, and exact searches
  for "Sensex", "Nifty 50" and "Indian stocks" returned nothing from that week.
  When the India section is empty it says so, and that RBI policy, the rupee,
  SEBI, the Union Budget and FII/DII flows must be reported as unavailable.
  With [Agent-Reach](agent-reach.md) switched on (optional), news comes from
  Exa's web search first, Yahoo being the fallback, and the India section is
  searched with multi-word topics that suit Exa (`agent_reach_india_queries`: RBI
  policy, Nifty and Sensex, FII/DII flows, the rupee, inflation, SEBI, the Union
  Budget, crude). Exa's dates come from the pages, so it is most reliable on runs
  dated today; when nothing it finds is dated in the window, Yahoo answers.
- **Company news** is often missing: on 2026-10-29 Yahoo had no article tagged
  RELIANCE.NS, and the news tool then reports company news as unavailable.
- **Insider transactions.** Yahoo states no currency for its insider rows. For
  RELIANCE.NS and INFY.NS on 2026-10-29, their per-share prices were about
  1/USDINR of the INR close on the same day. When the prices do not fit the
  stock's own closes over those dates, the tool adds a note that they are not
  rupee amounts. Indian insider trades are disclosed on NSE/BSE under SEBI's
  insider-trading (PIT) regulations, which this tool does not read.
- **Quarterly cash flow.** SEBI LODR requires a cash-flow statement half-yearly,
  with the half-year results, and on 2026-10-29 Yahoo had no quarterly one for
  RELIANCE.NS. When no vendor has one for an NSE/BSE company listing,
  `get_cashflow(freq="quarterly")` says why and points to `freq="annual"`; when
  Yahoo does serve one, it is passed through. An index (NIFTY 50, SENSEX) has
  no statements and gets the usual no-data message.

Choose vendors per category with `--vendor category=vendor` or the
`data_vendors` config (`core_stock_apis`, `technical_indicators`,
`fundamental_data`, `news_data`, `macro_data`, `market_context`,
`corporate_actions`); a vendor that fails yields a "data unavailable" notice,
never an invented figure.

### Not integrated, and why

| Source | Status |
|---|---|
| NSE / BSE official feeds | Licensed. NSE Data & Analytics publishes tariffs (end-of-day about ₹1 lakh a year per segment; real-time vendor feeds tens of lakhs a year; check NSE's tariff PDFs). NSE's website terms prohibit automated data collection, so nothing here scrapes nseindia.com or bseindia.com. |
| Broker APIs (Zerodha Kite Connect ₹500/month, Upstox, Dhan ₹499/month, Angel One SmartAPI) | Need a brokerage account and credentials, which this research tool does not use. Kite's terms forbid redistributing its data. |
| EODHD, Twelve Data, Financial Modeling Prep | Paid for Indian coverage (EODHD from $19.99/month personal use; Twelve Data's India plan from $329/month; FMP's global plan $139/month). Could be added as vendors. |
| Indian news RSS (Economic Times, Mint, Business Standard, BusinessLine, Moneycontrol) | Not added: their feed terms could not be verified, and Business Standard's terms bar automated access. Yahoo news and India-focused news searches are used instead, and they carry little India news (see above); the optional Agent-Reach web search is another route ([docs/agent-reach.md](agent-reach.md)). |

**Not available at all:** FII/DII daily flows, promoter holdings and pledges, F&O
open interest, exchange announcements, a stock's own price band, live quotes.
The agents are told these are unavailable. SEBI PIT insider disclosures are not
read either; the agents are told so only when Yahoo's insider prices do not fit
the stock's closes. Quarterly cash-flow statements are often missing (see
above).

## Charges and tax (examples, configurable)

`india_equity_delivery` (default for NSE/BSE) and `india_equity_intraday`, in
`tradingagents/markets/costs.py`, as of 2026-10-29:

| Charge | Delivery | Intraday | Source |
|---|---|---|---|
| Brokerage | ₹0 | lower of 0.03% and ₹20 | a discount broker (Zerodha) |
| STT | 0.1% buy and sell | 0.025% sell | NSE/FATAX/73524 |
| Exchange charge | NSE 0.00307%, BSE 0.00375% | same | NSE/FA/73061; broker page for BSE |
| SEBI fee | ₹10 per crore | same | NSE/FA/40632 |
| Stamp duty | 0.015% buy | 0.003% buy | Indian Stamp Act Sch. I |
| GST | 18% on brokerage, exchange and SEBI charges | same | |
| DP charge | ₹15.34 per sell (incl. GST) | none | a discount broker |

Capital gains on listed shares (`india_listed_equity`): 20% short-term (held up
to 12 months), 12.5% long-term above ₹1.25 lakh a year (Income-tax Act 2025
s.196 / s.198, formerly s.111A / s.112A; unchanged by Budget 2026); surcharge
and cess not included. Override any field in config, e.g.
`cost_overrides={"brokerage_rate": 0.001, "brokerage_cap": 20}`, or set
`cost_profile` to `none`. Intraday mode sizes and scores its paper plans with its
own settings, `intraday_cost_profile` (default `india_equity_intraday`) and
`intraday_cost_overrides`, not `cost_profile` and `cost_overrides`
([docs/intraday.md](intraday.md#charges)).

## Paper trading, and why no public arena

Everything here is paper: a swing decision goes into the local memory log, and an
intraday plan is scored there on its session's bars. Decisions on NSE/BSE
listings are never sent to AlphArena, the optional public paper-trading arena
for US stocks ([docs/arena.md](arena.md)); `tradingagents arena close` refuses
them too. SEBI's press release No. 27/2024 (4 Nov 2024) says apps "offering
virtual trading services or paper trading or fantasy games to the public based
on stock price data of listed companies" violate the Securities Contracts
(Regulation) Act and the SEBI Act, and its circular of 24 May 2024 bars
exchanges and intermediaries from sharing real-time price data with third
parties, citing such platforms. This is not legal advice.

|---|---|

| `TRADINGAGENTS_BENCHMARK_TICKER` | index to measure decisions against (default: NIFTY 50 / SENSEX by listing) |

| `TRADINGAGENTS_DECISION_HORIZON`, `TRADINGAGENTS_INTRADAY_SQUARE_OFF` | `intraday` for a one-session paper plan; your broker's MIS square-off, HH:MM IST (default 15:10; [docs/intraday.md](intraday.md)) |
| `TRADINGAGENTS_INTRADAY_COST_PROFILE` | charges for intraday plans: `india_equity_intraday` (default) or `none`; per-field overrides with `intraday_cost_overrides` ([docs/intraday.md](intraday.md#charges)) |
| `TRADINGAGENTS_AGENT_REACH` | news from Exa's web search first ([docs/agent-reach.md](agent-reach.md)) |
| `FRED_API_KEY`, `ALPHA_VANTAGE_API_KEY` | optional data vendors |

Keys belong in the environment or `.env`; none is written to reports or logs.
